# Student Study Manager
A simple Python project to manage daily study tasks.
# Features
- Add study tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Exit the program
# Technologies Used
- Python
# How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `study_manager.py`.
4. Follow the options shown in the terminal.
