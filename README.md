# Student Study Manager 📚

A simple Python-based application designed to help students organize their daily study tasks and track their progress.

## 🌐 Live Demo

[**Launch Student Study Manager**](https://student-study-manager-tbohcnrs7m9fz7erebm8vz.streamlit.app/)

## ✨ Features

- Add study tasks with subjects and deadlines
- View and search study tasks
- Mark tasks as completed
- Delete tasks
- Track completed and pending tasks through a dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- JSON for local task storage

## 🚀 How to Run Locally

1. Clone this repository.

2. Install the required dependency:

   `pip install -r requirements.txt`

3. Run the web application:

   `python -m streamlit run app.py`
